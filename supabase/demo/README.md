# 시연용 학습 기록 (학급 0000)

학급 코드 **0000**의 학생 4명(정민지·정민영·이소미·박준혁)에게 2026-04-06 ~ 2026-10-08 수업일의
풀이 기록(answer_logs)을 만들어 준다. 실제 학생의 기록이 아니라 **시연용으로 만든 기록**이다.

| 파일 | 하는 일 |
|---|---|
| `시연기록_만들기_0000.sql` | Supabase SQL Editor에 붙여넣고 Run. 학급 0000에 있는 수학 문제 중에서 골라 기록을 만든다. 여러 번 실행해도 됨(이전 시연 기록을 지우고 다시 만듦) |
| `시연기록_지우기_0000.sql` | 시연 기록만 깨끗이 지운다 (문제 오답률도 원래대로) |

- 시연 기록의 id는 모두 `dec0de00-`로 시작한다 — 실제 기록과 섞이지 않고 이것만 골라 지울 수 있다.
- 학생 프로필: 정민지(수 세기 → 받아올림 있는 두 자리 수 덧셈), 정민영(곱셈의 뜻 → 곱셈구구 → (몇십몇)×(몇)),
  박준혁(분수·분수의 덧셈과 뺄셈, 시각·시간, 길이·거리 단위 — 4월보다 크게 향상), 이소미(박준혁과 비슷한 영역, 더 낮은 성취).
- 포인트·레벨·도감은 바꾸지 않는다. 학생 가입일은 첫 기록 전(2026-04-03)으로 맞춘다.
