# 시연용 활동 기록 (학급 0000)

학급 코드 **0000**의 학생 4명(정민지·정민영·박준혁·이소미)에게 2026-04-06 ~ 2026-10-08 수업일 동안
이 프로그램으로 공부한 것처럼 **시연용 활동 기록**을 만든다. 실제 학생의 기록이 아니다.

| 파일 | 하는 일 |
|---|---|
| `시연기록_만들기_0000.sql` | Supabase SQL Editor에 통째로 붙여넣고 Run |
| `시연기록_지우기_0000.sql` | 시연 전 상태로 완전히 되돌림 |

## 만드는 것
- 풀이 기록 약 4,800개: 문제풀이 · 배틀 · 레이드(한 달에 한 번, 6회) — 학급 0000에 있는 수학 문제에서 고름
- 학생 상태: 포인트(벌고 쓴 결과) · 레벨/경험치 · 가방 · 배틀 포켓몬과 진화 · 도감 보상 · 가입일(4/3)
- 도감: 스타팅 · 배틀 포획 · 야생 탐색 · 진화 · 레이드 보상 포켓몬 (1세대)
- 문제 은행 오답률(푼 횟수/틀린 횟수)

## 학생 모습 (월별 정답률 4월 → 10월)
| 학생 | 내용 |
|---|---|
| 정민지 | 수 세기·가르기·덧셈 — **정답률은 47~55%로 거의 그대로**, 대신 **참여도가 늘어남** (수업일 중 활동한 날 4월 32% → 9월 95%, 푼 문제 월 84개 → 354개) |
| 정민영 | 곱셈의 뜻 → 곱셈구구 → (몇십몇)×(몇): 31 → 39 → 51 → 58 → 68 → 77 → 80% |
| 박준혁 | 분수·분수의 덧셈과 뺄셈, 시각·시간, 길이·거리 단위: 39 → 45 → 54 → 68 → 80 → 84 → 88% |
| 이소미 | 박준혁과 같은 영역, 매달 박준혁보다 낮게: 18 → 27 → 35 → 43 → 55 → 60 → 63% |

포켓몬은 학급 0000의 등장 세대(1·5·6·9세대, 499종)에서 등급별로 고르게 잡힌다 (학생당 도감 112~131종).
레이드 보스: 잠만보 · 레시라무 · 프리져 · 제르네아스 · 코라이돈 · 뮤츠.

## 안전장치
- 실행 전 4명의 원래 상태·도감을 `demo_backup` 표에 보관 → 지우기 SQL이 그대로 복원하고 표도 지움
- 시연 풀이 기록 id는 모두 `dec0de00-`로 시작 → 다른 기록은 건드리지 않음
- 여러 번 실행해도 됨 (보관본은 처음 것을 유지)
