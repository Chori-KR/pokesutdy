# 문제 은행 만들기 (Claude가 직접 제작)

Codex 대신 Claude가 문제를 만들어 `banks/bank_*.json`으로 저장한다.
선생님은 앱의 **문제 은행 → 🗂️ JSON 가져오기**로 넣는다. (앱 코드와 무관한 폴더 — 빌드·배포에 영향 없음)

## 한 묶음 만드는 순서

1. `standards/…/<과목>_<학년군>_<영역>.md`의 **대상 성취기준**과 문항 수를 읽는다
2. `sets/`에 새 파일을 만든다 (기존 `sets/수학_초3-4_자료와가능성.py`를 본보기로)
   - 그래프·표 그림은 **문제 숫자로 `svgkit`이 그리게** 하고, 정답도 같은 숫자로 계산한다 (그림↔정답 불일치 방지)
   - 객관식은 `answer=정답값`으로 주면 위치는 자동. 단답형은 `answers=[허용 정답…]`
3. 실행 → 점검
   ```bash
   cd tools/question-bank
   python3 sets/<파일>.py                     # errors [] 여야 함, 정답 위치(answer pos)가 고르게
   mkdir -p preview
   python3 preview.py preview/p.html "제목" banks/<파일>.json
   node shot.js preview/p.html preview/shots   # broken images 0 이어야 함
   cd ../.. && npx tsx tools/question-bank/check.ts   # 오류 0
   ```
4. `preview/shots/*.png`를 몇 장씩 붙여 **직접 눈으로 본다** — 그림 겹침·너무 빽빽한 눈금·어색한 문장을 고친다
5. 정답 위치가 한쪽으로 몰리면 보기(오답)를 바꿔 고르게 맞춘다 (보기 순서만 바꾼 문제 금지)
6. 선생님께 드릴 것: `banks/`의 JSON + 미리보기 HTML 하나로 합친 것
7. 커밋은 `test` 브랜치에만. `main`(진짜 사이트)은 선생님이 말할 때까지 건드리지 않는다

## 출제 규칙 (요약 — 자세한 것은 standards 파일)

- 난이도 = 성취수준: C→easy, B→medium, A→hard. 수학은 성취기준당 9문제(난이도별 3), 다른 과목 6문제(난이도별 2)
- 단답형은 전체의 2~3할. 같은 소재를 단답형·객관식으로 두 번 내지 않기
- 본문이 "아래 그림/그래프/표"를 말하면 반드시 `svg`. 같은 SVG 재사용 금지
- 그림: viewBox만, 글자 12 이상, 선 2 이상, 배경 없음, `currentColor` + 파랑 `#4b7bec`/주황 `#e07b39`만, **색만으로 구분하지 않기**(모양·무늬·글자 함께)
- 학년 어휘에 맞추기. 1-2학년은 짧고 쉬운 문장
- 지문(긴 글)이 필요하면 `b.passage(...)` + `passage=` — 직접 지은 글은 출처를 비워 둔다(`직접 지음`으로 넘기면 자동으로 빈 칸). 교과서·작품 인용은 출처 필수, 원문을 정확히 아는 경우만
